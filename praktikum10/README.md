# MieAyamLezat — Situs Promo Responsif

Proyek sederhana untuk promosi produk mie ayam menggunakan pendekatan RWD dan Bootstrap.

Konten:
- `index.html` — halaman utama responsif.
- `css/styles.css` — styling tambahan.
- `js/script.js` — skrip kecil untuk form.

Menjalankan secara lokal:

1. Buka folder proyek di File Explorer.
2. Klik ganda `index.html` atau buka dari terminal/PowerShell:

```powershell
start "" "index.html"
```

Kustomisasi cepat:
- Ganti gambar di `index.html` dengan gambar produk Anda.
- Ubah teks, harga, dan kontak sesuai kebutuhan.

Jika ingin deploy, cukup unggah seluruh folder ke hosting statis (Netlify, GitHub Pages, Vercel, dsb.).
